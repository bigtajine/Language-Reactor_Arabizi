# Language Reactor — Arabizi

Language Reactor 6.0.1 modded to show Arabic transliteration as Arabizi (7=ح, 3=ع, 2=ء …).

- `arabizi.js` — the converter (letter rules + common-word vowel dictionary), prepended to `pageScript_lly/lln.min.js` and `content_dictionary.js`.
- Arabic added to the transliteration language lists.

Load unpacked in `chrome://extensions`, then enable *Show transliterations* in settings.
